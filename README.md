# 📈 Tinkoff Bonds Portfolio

Консольное приложение для анализа облигационного портфеля в **Т-Инвестициях**.

Приложение получает данные через API Т-Инвестиций и отображает подробную информацию по каждой облигации, а также сводную статистику по всему портфелю.

---

## Возможности

- Просмотр всех облигаций портфеля
- Сортировка по названию
-Агрегация позиций по FIGI со всех брокерских счетов
- Параллельные запросы портфелей (gRPC-канал SDK потокобезопасен)
-Кеширование справочных данных по облигациям
- Общая информация по портфелю:
  - количество облигаций;
  - сумма вложений;
  - текущая стоимость портфеля;
  - изменение стоимости в процентах;
  - купонная доходность (до/после НДФЛ);
  - средневзвешенная доходность к погашению (до/после НДФЛ)

- Информация по каждой облигации:
  - название;
  - дата погашения;
  - номинал;
  - наличие амортизации;
  - информация о флоатере;
  - средняя цена покупки;
  - количество бумаг;
  - количество купонов в год;
  - размер ближайшего купона (до/после НДФЛ);
  - доля выпуска в портфеле;
  - текущая купонная доходность (до/после НДФЛ);
  - приблизительная доходность к погашению (YTM).

## Настройка

Создайте файл `.env`:

```env
TINKOFF_TOKEN = ваш_токен_Т-Инвестиций
TINKOFF_BROKER_ACCOUNT_IDS = идентификаторы_брокерских_счетов,через_запятую
```

Токен можно получить в личном кабинете Т-Инвестиций.

## Что отображается

### Общая информация

- Количество облигаций
- Общая сумма вложений
- Текущая стоимость портфеля
- Изменение стоимости относительно вложений (в процентах и в рублях)
- Купонная доходность портфеля (до/после НДФЛ)
- Средневзвешенная YTM портфеля (до/после НДФЛ)

### Для каждой облигации

| Поле | Описание |
|------|----------|
| Название | Наименование выпуска |
| Рейтинг | Кредитный рейтинг (если доступен) |
| Погашение | Дата погашения |
| Номинал | Номинальная стоимость |
| Аморт. | Наличие амортизации |
| Флоатер | Тип купона (+/-) |
| Покупка | Средняя цена покупки |
| Кол-во | Количество облигаций |
| Куп./год | Купонных выплат в год |
| Купон | Ближайший купон до / после НДФЛ |
| % портфеля | Доля выпуска в портфеле (по количеству) |
| Доходность | Текущая купонная доходность (до / после НДФЛ) |
| YTM | Приблизительная доходность к погашению (до / после НДФЛ)|

> Для облигаций с плавающим купоном значение **YTM** отображается с префиксом `~`, так как будущие купоны заранее неизвестны.

## Особенности расчётов

### Агрегация позиций
Позиции по одной и той же бумаге с разных счетов группируются по FIGI:

- количество — суммируется;
- цена покупки — средневзвешенная по количеству (на основе average_position_price_fifo);
- текущая цена — средневзвешенная по количеству.

### Купонная доходность

```
Годовой купон / Цена покупки × 100%
```

### Доля в портфеле

```
Количество облигаций / Общее количество облигаций × 100%
```

Отображается:

- до НДФЛ;
- после НДФЛ (13%).

### Доходность к погашению (YTM)

Используется приближённая формула:

```
(Годовой купон + (Номинал − Цена покупки) / Лет до погашения)
/ Цена покупки × 100%
```

Для облигаций с плавающим купоном расчёт является оценочным, так как размер будущих купонов зависит от ключевой ставки.

---

## Ограничения

- Кредитные рейтинги не предоставляются API Т-Инвестиций.
- Формула флоатера (КС + X%) также отсутствует в API.
- YTM рассчитывается приближённо и не учитывает:
  - изменение купонов;
  - реинвестирование;
  - налоги;
  - комиссии брокера;
  - НКД;
  - оферты.
