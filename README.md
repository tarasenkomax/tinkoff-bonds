# 📈 Tinkoff Bonds Portfolio

Консольное приложение для анализа облигационного портфеля в **Т-Инвестициях**.

Приложение получает данные через API Т-Инвестиций и отображает подробную информацию по каждой облигации, сводную
статистику портфеля, а также прогнозный календарь купонных выплат.

---

## Возможности

- Просмотр всех облигаций портфеля.
- Сортировка облигаций по названию.
- Агрегация позиций по FIGI со всех брокерских счетов.
- Расчёт средневзвешенной цены покупки и текущей стоимости.
- Параллельное получение данных по брокерским счетам.
- Параллельное получение справочной информации об облигациях.
- Кеширование справочных данных об облигациях и купонных событиях.
- Автоматическое сохранение данных портфеля в JSON-файл.
- Формирование купонного календаря на ближайшие 12 месяцев.
- Формирование месячной сводки купонных выплат.
- Расчёт фактически полученных купонов за текущий месяц.
- Расчёт прогнозируемого остатка купонных выплат.
- Группировка выпусков по эмитентам и расчёт их суммарной доли в портфеле.

### Общая информация по портфелю

- Количество облигаций.
- Общая сумма вложений.
- Текущая стоимость портфеля.
- Изменение стоимости в процентах и рублях.
- Купонная доходность (до/после НДФЛ).
- Годовая прибыль (до/после НДФЛ).
- Ежемесячная прибыль (до/после НДФЛ).
- Средневзвешенная доходность к погашению (YTM).

### Информация по каждой облигации

- Порядковый номер.
- Название.
- Кредитный рейтинг.
- Дата погашения.
- Номинал.
- Наличие амортизации.
- Информация о флоатере.
- Средняя цена покупки.
- Количество бумаг.
- Количество купонов в год.
- Размер ближайшего купона (до/после НДФЛ).
- Доля выпуска в портфеле.
- Суммарная доля эмитента в портфеле.
- Текущая купонная доходность (до/после НДФЛ).
- Приблизительная доходность к погашению (YTM).

### Купонный календарь

- Прогноз купонных выплат на 12 месяцев.
- Даты выплат по каждой облигации.
- Размер купона на одну облигацию.
- Прогнозная сумма выплаты по каждому выпуску.
- Общая сумма купонных выплат за месяц.
- Фактически полученные купоны за текущий месяц.
- Оставшаяся прогнозная сумма выплат.
- Сокращённая сводка по месяцам без детализации отдельных выплат.

## Пример купонного календаря

Календарь формируется на 12 календарных месяцев, начиная с текущего месяца.

### Подробный календарь

```text
НОЯБРЬ 2026 (+21 555.93 ₽) (выплачено: 13 587.12 ₽, осталось: 7 968.81 ₽)
01.11
  Легенда БО 002P-07                 37 x 13.59 ₽ = 502.83 ₽
  Селигдар 001Р-02                   22 x 17.17 ₽ = 377.74 ₽

04.11
  АПРИ БО-002Р-13                    50 x 18.25 ₽ = 912.50 ₽

ДЕКАБРЬ 2026 (+26 155.56 ₽)
03.12
  ОФЗ 26254                          10 x 30.00 ₽ = 300.00 ₽
```

### Месячная сводка

Доступен сокращённый вариант календаря без детализации отдельных дат и облигаций:

```text
НОЯБРЬ 2026         (+21 555.93 ₽) (выплачено: 13 587.12 ₽, осталось: 7 968.81 ₽)
ДЕКАБРЬ 2026        (+26 155.56 ₽)
ЯНВАРЬ 2027         (+21 244.48 ₽)
ФЕВРАЛЬ 2027        (+18 500.00 ₽)
```

Все суммы прогнозных купонных выплат отображаются после удержания НДФЛ.

Для текущего месяца дополнительно отображаются:

- фактически полученные купоны;
- оставшаяся прогнозная сумма выплат.

Если оставшаяся сумма равна нулю или отрицательна, она не отображается.

## Настройка

Создать файл `.env` в корне проекта:

```env
TINKOFF_TOKEN=ваш_токен_Т-Инвестиций
TINKOFF_BROKER_ACCOUNT_IDS=идентификаторы_брокерских_счетов,через_запятую

# Верификация идёт по вшитому в библиотеку сертификату Минцифры
SSL_TBANK_VERIFY=True
```

Токен можно получить в личном кабинете Т-Инвестиций.

`TINKOFF_BROKER_ACCOUNT_IDS` — список идентификаторов брокерских счетов. При указании нескольких счетов приложение
агрегирует позиции по FIGI.

При запуске проверяется доступность указанных брокерских счетов.

## Архитектура

Приложение разделено на три слоя.

### 1. TinkoffInvestAdapter

Адаптер над SDK Т-Инвестиций.

Отвечает за взаимодействие с API:

- получение портфелей брокерских счетов;
- получение информации об облигациях;
- получение купонных событий;
- получение ближайших купонов;
- получение операций по брокерским счетам;
- кеширование справочной информации;
- параллельное получение портфелей нескольких счетов.

Адаптер скрывает детали SDK от бизнес-логики приложения.

### 2. BondService

Слой бизнес-логики.

Отвечает за:

- агрегацию позиций по FIGI со всех брокерских счетов;
- расчёт средневзвешенной цены покупки;
- расчёт текущей стоимости портфеля;
- расчёт доходности облигаций;
- расчёт купонной доходности;
- расчёт долей выпусков и эмитентов;
- формирование JSON портфеля (`get_portfolio_json`);
- формирование JSON купонного календаря (`get_coupon_calendar_json`);
- расчёт прогнозных купонных выплат;
- агрегацию фактически полученных купонов.

Сетевые запросы для получения справочной информации и купонов выполняются параллельно.

### 3. BondReport

Слой представления.

Отвечает за:

- парсинг JSON;
- вывод общей информации о портфеле;
- вывод таблицы облигаций;
- вывод подробного купонного календаря;
- вывод месячной сводки купонных выплат;
- форматирование денежных значений;
- сохранение JSON-файлов.

## Сохранение данных

Приложение поддерживает сохранение данных в формате JSON.

### Портфель

Данные портфеля сохраняются в папку:

```text
json_dumps/portfolio/
```

Имя файла формируется автоматически и содержит дату и время:

```text
json_dumps/portfolio/portfolio_2026-11-03_20-19-15.json
```

### Купонный календарь

Купонный календарь также можно сохранять в отдельную папку:

```text
json_dumps/coupon_calendar/
```

Пример имени файла:

```text
json_dumps/coupon_calendar/calendar_2026-11-03_20-19-15.json
```

Сохранение календаря настраивается отдельно от сохранения портфеля.

> Папка `json_dumps/` добавлена в `.gitignore`, так как содержит персональные финансовые данные.

## Особенности расчётов

### Агрегация позиций

Позиции по одной и той же бумаге с разных брокерских счетов группируются по FIGI.

- Количество — суммируется.
- Цена покупки — рассчитывается как средневзвешенная по количеству на основе `average_position_price_fifo`.
- Текущая цена — рассчитывается как средневзвешенная по количеству.

### Купонная доходность портфеля

```text
Σ(годовой купон по облигации × количество облигаций)
--------------------------------------------------- × 100%
                 Общая сумма вложений
```

### Текущая купонная доходность облигации

```text
Годовой купон облигации
----------------------- × 100%
      Цена покупки
```

### Доля в портфеле

Доля конкретного выпуска рассчитывается по количеству облигаций:

```text
Количество облигаций выпуска
---------------------------- × 100%
Общее количество облигаций
```

Дополнительно рассчитывается суммарная доля эмитента, если в портфеле присутствует более одного его выпуска.

### Доходность к погашению (YTM)

Используется приближённая формула:

```text
(Годовой купон + (Номинал − Цена покупки) / Лет до погашения)
---------------------------------------------------------------- × 100%
                       Цена покупки
```

Для облигаций с плавающим купоном расчёт является оценочным, так как размер будущих купонов зависит от ключевой ставки.

### Налогообложение

Для расчётов купонного дохода используется ставка НДФЛ 13%.

Приложение отображает:

- купонный доход до НДФЛ;
- купонный доход после НДФЛ.

Фактически полученные купоны в календаре берутся из операций брокера. Повторное удержание налога для таких операций не
производится.

## Особенности купонного календаря

### Период календаря

- Календарь формируется на 12 календарных месяцев.
- Начало периода — первое число текущего месяца.
- Даты купонных событий приводятся к московскому часовому поясу.
- В текущем месяце отображается текущая дата, даже если на неё не запланированы выплаты.

### Прогнозные выплаты

Для каждой облигации учитываются:

- дата купонной выплаты;
- размер купона на одну облигацию;
- количество облигаций;
- общая прогнозная сумма выплаты.

Прогнозные суммы рассчитываются после удержания НДФЛ.

### Флоатеры

Размер будущих купонов по флоатерам заранее неизвестен.

Если API не возвращает размер будущего купона, приложение использует последнее известное значение купона.

Такие выплаты являются прогнозными и могут отличаться от фактических.

### Фактически полученные купоны

Для текущего месяца дополнительно запрашиваются исполненные операции выплаты купонов.

Суммы фактически полученных купонов:

- группируются по FIGI;
- берутся непосредственно из операций брокера;
- не уменьшаются на НДФЛ повторно.

### Оставшаяся сумма выплат

Для текущего месяца рассчитывается разница между прогнозной суммой купонных выплат и фактически полученными купонами:

```text
Осталось = Прогноз выплат − Фактически получено
```

Если остаток равен нулю или отрицателен, он не отображается в консольном отчёте.

## Ограничения

- Кредитные рейтинги не предоставляются API Т-Инвестиций и заполняются вручную в `bonds/ratings.py`.
- Формула флоатера (ключевая ставка + надбавка) не предоставляется API.
- Будущие купоны флоатеров рассчитываются прогнозно на основе последнего известного значения.
- YTM рассчитывается приближённо и не учитывает:
    - изменение купонов;
    - реинвестирование;
    - налоги на разницу между ценой покупки и номиналом;
    - комиссии брокера;
    - накопленный купонный доход (НКД);
    - оферты;
    - досрочное погашение.
- Прогнозный купонный календарь может отличаться от фактических выплат.
- Для будущих выплат используются доступные на момент запроса данные API Т-Инвестиций.
